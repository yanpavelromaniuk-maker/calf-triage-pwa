# PRD — Calf Triage PWA (Триаж телят КРС)

Версия: 0.1.0-beta.1 · Дата: 2026-10-04 · Статус: бета, клинический контент ожидает ветеринарной валидации

## 1. Цель

Офлайн-помощник для первичной оценки состояния теленка КРС в возрасте до 6 месяцев. Приложение помогает:

1. определить **уровень срочности** обращения к ветеринарному специалисту;
2. сформировать **вероятные направления** (дифференциальные группы) для обсуждения со специалистом — с объяснением «что поддерживает / что против»;
3. подготовить **структурированную сводку** для ветеринара.

Приложение **не ставит диагноз**, не назначает лечение и не заменяет ветеринарную помощь.

## 2. Non-goals (вне объема)

- Лекарства, дозировки, инфузионные и хирургические протоколы.
- Гарантии диагноза; процентные «вероятности».
- Онлайн-консультации, сторонние AI/LLM API в runtime.
- Сбор персональных данных, телеметрия, аккаунты.
- Работа со взрослым скотом и телятами старше 180 дней.

## 3. Пользователи и сценарии

| Пользователь | Сценарий |
|---|---|
| Владелец теленка | Теленок поносит второй день → проходит опросник → видит «Срочно: ветеринар сегодня» + сводку для звонка специалисту |
| Зоотехник / фельдшер | Групповой падеж телят → проверяет red flags → готовит сводку → согласует действия с ветврачом |
| Студент ветвуза | Учебный кейс → смотрит, какие признаки поддерживают/против каждого направления |
| Ветеринар | Получает сводку (текст) с анамнезом, симптомами и уровнем срочности — экономит время на расспросе |

## 4. Функциональные требования

1. **Онбординг и дисклеймер** при первом запуске; дисклеймер доступен всегда (настройки + подвал).
2. **Возрастной шаг**: возраст в днях (0–180, обязательное поле), пол, порода/направление.
3. **Анамнез**: молозиво, кормление, содержание, подстилка, вентиляция, контакт с больными, вакцинация.
4. **Течение**: длительность симптомов, динамика (включая «резко ухудшается за часы»), примечание свободным текстом.
5. **Симптомы**: 39 позиций по 9 системам, поиск, аккордеоны по группам, возрастная фильтрация вопросов (напр. «плохо набирает вес» — только старшие группы).
6. **Измерения**: температура (опционально, число) и частота дыхания (опционально) с пометкой порогов как требующих ветвалидации.
7. **Триаж**: 4 уровня (экстренно / срочно / планово / наблюдение), определяется ТОЛЬКО red-flag правилами и severity-гейтами; диагностические баллы не могут повысить срочность выше консервативного «планово».
8. **Red flags**: 13 правил; при срабатывании — немедленный баннер с сообщением.
9. **Дифференциалы**: топ-5 кандидатов с категориальными полосами (вероятный / возможный / менее вероятно), доказательствами «за/против», особыми сочетаниями, недостающими данными, возрастным окном и пометкой зооноза.
10. **Rule-out заметки**: контекстные несскоринговые подсказки (грыжа, лишай, родовая травма, неинфекционный конъюнктивит).
11. **Сводка для ветеринара**: детерминированный текст; копирование, Web Share (если доступен), печать (print CSS).
12. **История**: opt-in, localStorage, последние 10 оценок, просмотр/удаление/очистка.
13. **Настройки**: история, повторный дисклеймер, версии приложения и БЗ, статус валидации.
14. **PWA**: установка, офлайн-работа целиком (app shell + база знаний в precache), автообновление SW.
15. **i18n**: русский (default), словарная структура готова к добавлению английского.

## 5. Нефункциональные требования

- **Determinism**: одинаковый ввод + версия БЗ → идентичный результат (покрыто тестом).
- **Объяснимость**: каждый балл трассируем до правила; пользователь видит «за/против/не хватает».
- **Приватность**: ноль сетевых запросов данных; история только локально и opt-in.
- **Производительность**: интерактивный офлайн-бандл; precache < 300 КБ.
- **A11y**: touch targets ≥ 44px, aria-pressed/aria-expanded/role=alert, фокус-ринги, контраст AA.
- **Mobile-first**: однаколоночная верстка, крупные контролы.

## 6. Safety requirements

1. Срочность не зависит от диагностических баллов (разделение модулей).
2. Никогда не выводится единственный диагноз; всегда список направлений «НЕ ДИАГНОЗ».
3. Всегда отображаются недостающие данные и «данных недостаточно» при пустом топе.
4. Консервативный дефолт: любые положительные клинические находки ⇒ минимум «планово».
5. Запрещенные действия («чего не делать») на экране результата.
6. Зооноз-предупреждения (криптоспоридиоз, сальмонеллез, дерматофития).
7. Дисклеймер на каждом экране (подвал) + полный дисклеймер.
8. Все числовые пороги помечены `needs-veterinary-review` в данных базы знаний; статус валидации и версии — только в «Настройках»: рабочие экраны (опросник → результат → сводка) свободны от технических меток и служебных пометок.
9. Возраст вне 0–180 → безопасный fallback «покажите специалисту».

## 7. Acceptance criteria

- [x] Полный сценарий (возраст → анамнез → течение → симптомы → результат → сводка) проходится на мобильном векторе офлайн.
- [x] Каждый red flag из KB поднимает уровень до «экстренно» (golden-тесты).
- [x] Смена возраста меняет состав дифференциалов (гейтинг окна; тест).
- [x] Неотвеченные ключевые вопросы появляются в «Уточнить для оценки» (тест).
- [x] Явные отрицательные ответы («нет диареи») понижают релевантность ЖКТ-направлений (тест).
- [x] Одинаковый ввод дает идентичный вывод (тест).
- [x] `npm test` зелен (44 теста), `npm run build` успешен, dist содержит manifest + sw + 404.
- [x] База знаний редактируется без правки движка (данные отдельно; инварианты в тестах).
- [x] Ни одного сетевого вызова данных приложения; ноль телеметрии.
- [x] Пороги температуры/ЧСС помечены как требующие ветревью (тест проверяет `basis`).

## 8. Метрики успеха (без телеметрии — качественные)

- Владелец завершает триаж ≤ 5 минут.
- Ветеринар называет сводку полезной для первичного телефонного контакта.
- Ни одного сообщения о «пропущенном экстренном случае» при корректно отмеченных симптомах.

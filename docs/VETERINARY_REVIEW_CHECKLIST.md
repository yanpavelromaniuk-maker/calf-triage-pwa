# Чек-лист ветеринарной валидации

Статус БЗ: **pending-review** (бета). Ни один пункт этого чек-листа нельзя отметить, не проверив по авторитетному источнику.

## Как работать с чек-листом

1. Проверять пул-реквест с изменениями KB (или файлы `src/domain/kb/*`).
2. Для каждого утверждения — авторитетный источник: ветеринарные справочники/мануалы, университетские клинические руководства по болезням молодняка КРС, материалы национальных ветеринарных служб и профильных ассоциаций специалистов по КРС.
3. Отмечать статус элемента в коде: `pending-review` → `vet-approved` (или правка + комментарий ревьюера).
4. При правках — bump `KB_VERSION` и `KB_DATE` в `src/domain/kb/index.ts`, запись в CHANGELOG.
5. Прогнать `npm test` — инварианты БЗ должны остаться зелеными.

## A. Возрастные окна (`conditions[].ageWindow`)

- [ ] Колибактериоз (ЭТЭК) 0–7 дн.; ротавирус/коронавирус 3–28 дн.; криптоспоридиоз 5–30 дн.
- [ ] Сальмонеллез 14–180 дн. (Merck/MSD: «usually is not seen in calves < 14 days old», серовары Typhimurium/Dublin — телята 2–12 недель); кокцидиоз 21–180 дн. (Merck: «3 weeks to 6 months» — сверено); BRD-комплекс ≥21 дн.
- [ ] Кормовая диарея 0–21 дн. (Merck: неосложненная кормовая диарея < 3 недель); «вялость» для нее — признак «против» (Merck: телята изначально активны)
- [ ] Rule-out «Геморрагическая энтеротоксемия (C. perfringens) / AEEC» показывается при заметной крови в кале у телят ≤ ~2 мес (Merck: главные дифференциалы кровавой диареи у очень молодых телят)
- [ ] Септицемия 0–10 дн.; омфалит 0–21 дн.; joint ill 0–35 дн.; гипогликемия 0–7 дн.; гипотермия 0–30 дн.; неврологический синдром 0–30 дн.; абомазальное вздутие 0–30 дн.; тимпания рубца ≥30 дн.; IBK ≥14 дн.; микоплазменная инфекция ≥21 дн.

## B. Числовые пороги (`symptoms.ts` ranges)

- [ ] Гипотермия ≤ 38,0 °C; лихорадка ≥ 39,5 °C; выраженная лихорадка ≥ 40,5 °C (ректально, телята).
- [ ] Тахипноэ ≥ 80 дых/мин; выраженное ≥ 120 дых/мин (покой, телята).
- [ ] Ориентир нормы в подсказках (≈38,5–39,5 °C; ≈30–60 дых/мин) корректен для телят.

## C. Красные флаги (`triage.ts` redFlags)

- [ ] Полный список из 13 правил: лежачее состояние; судороги; опистотонус; ступор; дыхание с открытым ртом/цианоз; гипотермия (измеренная и клиническая); лихорадка ≥40,5; выраженное обезвоживание; резкое ухудшение; кровавая диарея + системные признаки; пупочные гнойные выделения + системные признаки; отказ от молока >12–24 ч + вялость у новорожденных.
- [ ] Формулировки сообщений безопасны (без самолечения, с немедленным обращением к специалисту).

## D. Severity-гейты

- [ ] Соответствие «этажей» срочности клинической логике: умеренное обезвоживание/кровь в кале/лихорадка/длительный отказ от корма/падеж в группе/припухший сустав ⇒ «срочно»; начальное обезвоживание/тенезмы/тахипноэ ⇒ «планово».

## E. Ассоциации и веса (`rules.ts`)

- [ ] Вес 4–5 только для признаков с сильной диагностической связью; вес 1–2 — для слабых.
- [ ] «Против»-правила корректны (напр., лихорадка против ЭТЭК; нормотермия против сальмонеллеза).
- [ ] Взаимодействия (7 шт.) клинически оправданы; пометка «требует проверки» снята или подтверждена.

## F. Тексты для пользователя

- [ ] Описания состояний не содержат рекомендаций лечения и не создают ложной уверенности.
- [ ] Зооноз-статус: криптоспоридиоз, сальмонеллез (+ дерматофития в rule-out) — верен.
- [ ] RU-формулировки однозначны для неспециалиста.

## G. Чего в БЗ быть не должно (out-of-scope)

- [ ] Нет дозировок, схем лечения, протоколов инфузии.
- [ ] Нет нутритивных диагнозов как факта (дефициты — только повод для осмотра).
- [ ] Нет утверждений цвета кала → возбудитель (наблюдение без интерпретации).

## Критерий переключения статуса БЗ

`kb.reviewStatus = 'vet-approved'` допустим только когда: все разделы A–G отмечены разными ревьюерами (минимум один ветеринарный врач, работающий с молодняком КРС), спорные пункты исправлены, тесты зеленые, версия поднята.

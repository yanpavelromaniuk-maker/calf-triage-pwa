# Changelog

Формат — Keep a Changelog; версионирование — Semver. Версии БЗ знаний (`KB_VERSION` в `src/domain/kb/index.ts`) синхронизированы с версиями приложения.

## [0.1.2-beta.1] — 2026-10-04

Полная повторная сверка диагнозов с источниками + зачистка пользовательского интерфейса.

### Changed (UX — по решению владельца продукта)
- С рабочих экранов (опросник → результат) убраны технические элементы: метки уверенности правил на карточках направлений, внутренние примечания сработавших взаимодействий, бейдж «база знаний ожидает валидации», версия БЗ. Вся служебная информация осталась в «Настройках».
- Сводка для ветеринара: убрана строка версии/статуса БЗ; строка «Не является диагнозом» сохранена.
- Подсказки измерений (температура, ЧДД) без хеджирующих вставок — пороги по-прежнему помечены `needs-veterinary-review` в данных БЗ и чек-листе ветревью.
- Дисклеймеры, зооноз-предупреждения и «чего не делать» сохранены полностью (safety).

### Added
- Пояснение о **смешанных инфекциях** в результатах и сводке: моно-инфекции — учебная абстракция; ко-инфекции у телят часты (ротавирус+криптоспоридий, рота+корона и др.) и протекают тяжелее моно-инфекций (Torreggiani 2025, PMC; Conrady 2021, MDPI; Clemson Extension). Перечень направлений читается как набор, а не выбор одного диагноза.

### Verified (дополнительная сверка)
- **Микоплазма bovis**: отит среднего уха (наклон головы — самый частый признак, бывает двусторонним) + полиартрит + хроническая бронхопневмония; preweaned телята, ~3 нед — несколько мес (Francoz 2004, PMC546444; J Vet Diagn Invest 1997; Berman 2021, JDS). Триада в interactions БЗ подтверждена.
- **Септицемия/менингит**: Merck — острая форма <7 дн (на фоне FPT, E. coli — основной агент), локализованная форма 7–28 дн (менингит, артрит, гипопион, пневмония). Лиxорадка при ранней септицемии часто ОТСУТСТВУЕТ (Peek 2018, PMC7152230) — в БЗ корректно нет «против нормотермии» для септицемии; признаки менингита (вялость, лежание, отказ от сосания; реже опистотонус/судороги) совпадают с набором неврологического синдрома.
- Гипотермия/гипогликемия, тимпания рубца — общепризнанные синдромы; числовые пороги — на ветревью (не менялись).

## [0.1.1-beta.1] — 2026-10-04

Клинический контент сверен с Merck/MSD Veterinary Manual (Diarrhea in Neonatal Ruminants; Coccidiosis of Cattle) и университетскими источниками. Статус: по-прежнему **pending-review** — сверка с источниками не заменяет независимую ветеринарную валидацию.

### Changed
- **Сальмонеллез**: возрастное окно 3–180 → **14–180 дней** (Merck: «usually is not seen in calves < 14 days old»; в этиологии — телята 2–12 недель).
- **Кормовая диарея**: окно 0–90 → **0–21 день** (Merck: неосложненная кормовая диарея — «calves < 3 weeks old»); находка «вялость» переведена из поддерживающих в **«против»** (Merck: «bright and alert and have good appetites») — помечено needs-veterinary-review.
- **Ротавирусная/коронавирусная диарея**: добавлена слабая поддержка «слизь в кале» (вес 1; Merck: «feces often contain large amounts of mucus»).

### Added
- Rule-out заметка **«Геморрагическая энтеротоксемия (C. perfringens) / AEEC»** — показывается при заметной крови в кале у телят ≤ ~2 мес (Merck: главные дифференциалы кровавой диареи у очень молодых телят). Нескоринговая, с призывом к срочному осмотру.
- `RuleOutDef.ageBands` — rule-out заметки теперь могут ограничиваться возрастными группами (движок фильтрует по band кейса).

### Verified
- Сверка с источниками подтвердила: окна криптоспоридиоза (5–35 дн) и кокцидиоза (3 нед–6 мес) совпали практически дословно; FPT как фактор септицемии; последовательность омфалит → септицемия/артрит; «против лихорадки» для ЭТЭК; зоонозность криптоспоридиоза и сальмонеллеза; обезвоживание/лежачее состояние как маркеры тяжести.

## [0.1.0-beta.1] — 2026-10-04

Первый MVP-релиз (этап 2 проекта). Статус клинического контента: **pending-review** — база знаний ожидает ветеринарной валидации.

### Added
- Детерминированный триаж-движок: weighted rule-based скоринг, возрастные окна и множители, red-flag override (13 правил), severity-гейты (12), категориальные полосы правдоподобия вместо процентов, missing-data список, rule-out заметки.
- База знаний: 39 симптомов (9 систем), 11 факторов анамнеза, 18 состояний-дифференциалов, ~180 ассоциаций, 7 взаимодействий; уровни уверенности и статусы ревью на каждом элементе.
- Шаблонная генерация сводки для ветеринара (копирование / Web Share / печать).
- Мастер-опросник (5 шагов): возраст → анамнез → течение → симптомы (поиск, аккордеоны, возрастная фильтрация) → проверка.
- Результат: баннер срочности, red flags, топ-5 направлений с «за/против», недостающие данные, «чего не делать», зооноз-предупреждения.
- PWA: манифест, иконки (генератор на чистом Node), precache SW, offline-режим целиком, autoUpdate.
- GitHub Pages деплой: автоматический base path, 404.html redirect, permissions по минимуму.
- Тесты: 44 (инварианты БЗ, golden-кейсы движка, сводка, конфиг PWA/CI, UI smoke).
- Документация: PRD, архитектура, дисклеймер, чек-лист ветревью, гайд по БЗ, деплой, тестирование.

### Safety
- Срочность определяется только red flags и гейтами; диагностические баллы не могут поднять уровень выше «планово».
- Никаких лекарств/дозировок/протоколов; никаких процентов вероятностей; едиственный диагноз запрещен.
- Числовые пороги (температура, ЧСС) помечены как требующие ветеринарной валидации.
- Приватность: без телеметрии и сетевых запросов данных; история — opt-in, localStorage, ≤10 записей.
